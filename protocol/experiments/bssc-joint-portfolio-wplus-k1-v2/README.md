# BSSC local joint portfolio/W+ K1 experiment V2

This unpublished, publication-forbidden experiment is the additive successor to
V1. V1 recovered the desired code-induced-converse subtree but also invented
unaffected achievability and alternative-converse branches, and represented the
existing root as a newly created program.

V2 makes the incremental locality boundary part of the response contract:

- `createdPrograms` contains new programs only;
- the existing root has separate boundary and `W+` annotation objects;
- each fixed intermediate result has one narrowest primary program and no
  ancestor membership links;
- every created leaf owns a fixed result; and
- every created internal program has at least two created children, excluding
  speculative leaves and unary wrappers from the minimal ancestor closure.

The judge still decides the accounting topology. In particular, the validator
does not require a fixed program count or mechanically require a common parent.
The precommitted K1 relational gold remains the empirical gate: one narrow
parent with two independently estimable result-owning leaves.

The root `W+` estimate must retain unresolved terminal work that is not
represented by the local children, without duplicating child work. K2 remains a
holdout and is not dispatched unless K1 passes.

Observed run evidence is recorded in `results-run-33560558307.md`. Its exact
accepted post-state and live W+ state are frozen only in the additive K2 V3
successor; the V2 manifest and provider contract remain unchanged for replay.
