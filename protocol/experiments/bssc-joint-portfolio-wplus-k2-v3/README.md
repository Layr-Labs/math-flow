# BSSC joint portfolio/W+ K2 V3 experiment

This additive, unpublished experiment continues from the exact successful K1
knowledge state and live W+ state produced by GitHub Actions run 33560558307.
It tests whether one joint judge can extend the accounting topology for K2 and
estimate the resulting W+ primitives without redesigning or re-estimating the
unaffected K1 subtree.

The V3 mechanical change makes every newly created program active in the
provider schema and requires every fixed newly created result to be active.
This aligns the response contract with the research-builder reducer. Existing
V1 and V2 manifests, prompts, and run evidence remain unchanged.

The K2 semantic packet is fixed before topology judgment. It preserves the
two-result split accepted by the prior local-builder K2 holdout, translated
only so its narrow BSSC specialization depends on the result ID actually
created by the successful joint K1 run.

The topology gate is still judgment-bearing. The schema does not prescribe
whether the new program is a child of root or of the K1 portfolio. The
precommitted scorer requires one new root child because mathematical use of a
K1 result is not accounting ancestry when the UV route has an independently
variable inclusion and stopping policy.

Publication is forbidden. The workflow must run with `continue=false`.

The observed K2 outcome is recorded in `results-run-33564954137.md`.
