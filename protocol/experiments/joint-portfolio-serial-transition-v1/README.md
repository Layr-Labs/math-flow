# Provider-free joint portfolio serial-transition V1

This additive, inactive fixture exercises the generalized transition boundary
that follows the successful K2 joint topology/W+ experiment. It makes no
provider call, publishes nothing, and is not referenced by a governed judge or
projection.

The three ordered cases isolate the transition classes needed before a hosted
miniature is credible:

1. K1 creates a result-owning root-child program and its initial live W+ state.
2. K2 creates an independent root-child route while preserving every K1
   primitive.
3. K3 refreshes the exact K2 program and result IDs, adds evidence and
   provenance, creates no entity, and emits a sparse W+ patch.

The fixture is relational rather than a frozen model transcript. The unit test
constructs exact digest-bound semantic packets, V10 local authoring scopes, and
responses from the stable identifiers in `scenario-v1.json`, then applies the
real state-v3/V10 and Work Accounting reducers. Negative cases cover stale
state, rehashed evidence substitution, out-of-scope writes, and attempts to
replace the K3 refresh with a duplicate result.

The adjacent inactive credit adapter then freezes that reducer-authored W+
state, exposes only safe facts and structural context to a no-access W- stage,
and derives positive D and its node effects in trusted code. The credit tests
exercise all three transitions, direct submission allocation, node-effect
conservation, checkpoint replay, a nonpositive W- rejection, frozen-candidate
tampering, and stale joint input.

This milestone stops before a provider implementation or projection bundle.
It does not define scheduling, governance, publication, CLI, or UI behavior.
