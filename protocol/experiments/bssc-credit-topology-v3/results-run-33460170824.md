# Results: run 33460170824

GitHub Actions run: <https://github.com/Layr-Labs/math-flow/actions/runs/33460170824>

This was an unpublished, non-canonical sequential K2/K3 holdout. Two
independent seeds started from the same frozen accepted K1 state. Each seed
first organized K2 and then supplied its own accepted K2 state as the base for
K3. The production job was skipped and no projection state was published.

## Candidate under test

The candidate made prompt-level changes only. It did not change the state
schema, reducer, validators, or production projection. Relative to the refined
K1 candidate, it generalized four controls:

1. use an author-blind intervention test for program boundaries: split only
   when plausible future accepted evidence could independently change the
   continue, stop, solve, or prune decision for one work package;
2. use the narrowest genuine shared activation parent, reject generic umbrellas,
   and keep mathematical dependency distinct from accounting ancestry;
3. link a result only to the narrowest program whose own remaining work it
   directly changes, while preserving stable IDs for later evidence about the
   same program or semantic result; and
4. treat the accepted claim assessments as joint upper bounds on every output
   surface, preserve their weaker intersection and modal force, and obey the
   topology/content operation contract on the first response.

The experiment harness, frozen base fixture, relational gold, and branch-only
workflow job were mechanical additions needed to run and audit the holdout.

## The intermediate-result mismatch

The precommitted gold separated the general averaged-scalar product theorem
from the receiver-skew/branchwise/BSSC specialization. Both judges instead
created one aggregate result for the dependency-ordered theorem chain. Their
placement rationales explicitly said that the components govern the same
blocking-converse decision and should be consolidated.

This is a real mismatch with the frozen gold, but it is not evidence of a bad
credit boundary:

- work accounting is attached to programs, and both put all of the affected
  work in the same independently updateable UV program;
- the accepted K2 statement itself describes the claims as one
  dependency-ordered theorem chain; and
- the simplified knowledge model intentionally lets one intermediate result
  package a result, method, computation, and proof that are normally consumed
  together.

There remains a knowledge-reuse argument for two results: the general product
theorem has broader scope and the BSSC specialization depends on both it and a
prior BSSC result. A downstream contribution might cite the general theorem
without consuming the specialization. That is a semantic retrieval concern,
not a reason to create two credit programs.

The evidence therefore supports accepting the candidate's program behavior
while treating result granularity as a separately scored policy choice. A
future gold should require separate results only when they have materially
different downstream consumers, qualifications, supersession paths, or
dependency edges—not merely because a proof has identifiable lemmas and
corollaries.

## Context observations

The initial K2 request was large even in this three-transition fixture:

| --- | ---: | ---: |
| K2, seed 1729 | 45,648 | 78,070 |
| K2, seed 2718 | 45,648 | 78,070 |
| K3, seed 1729 attempt 1 | 16,768 | 33,919 |
| K3, seed 2718 | 16,852 | 34,115 |

K2 is dominated by the submission evidence packet, not accumulated state. K3
is smaller because its repository evidence is smaller even though its state is
larger. Builder V9 omits full support bodies for results outside the declared
dependency closure, but still sends the structural and semantic record for
every program and every intermediate result. Its state component therefore
continues to grow with problem history.

Work-accounting V2 already uses a bounded impact subgraph: seed programs,
ancestors, siblings at the decision point, descendants to a configured depth,
collapsed boundary counts, and structural-only intermediate-result references.
It does not send result statements or support bodies through the shared
no-access context. This substantially reduces long-history risk for W+ and W-,
but the safe-facts and with-access stages still carry the complete current
submission evidence, and large local subtrees can still exceed practical
budgets.

The run demonstrates two distinct scale risks that must be measured separately:

1. input growth from evidence and accumulated state; and
2. output truncation or pathological generation even when the input is modest.

It does not yet measure degraded judgment quality before a hard limit, such as
lost-in-the-middle failures.

## Decision

The generalized candidate passes the K2/K3 holdout at the program-accounting
level and is a reasonable basis for a full credit-assignment candidate. It
should not yet be promoted solely on the literal gold score, because the gold's
two-result rule needs to be made conditional on actual downstream reuse rather
than treated as an accounting invariant.

The next paid experiment should be an end-to-end shadow lane, not another
prompt-only K2/K3 sample: build a complete small knowledge history with this
candidate, run W+ then same-world W- per submission from zero, and audit both
topology and numeric accounting. Before that spend, add provider-free request
telemetry and scale fixtures so every stage reports its input/output budget and
the experiment has explicit stop thresholds.
